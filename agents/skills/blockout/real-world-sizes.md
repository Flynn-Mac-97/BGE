# Real-world sizes

239 sourced dimensions in metres, as `width x depth x height`.

**Grep this file. Never read it whole.** It is a table, not a document.

```
Grep(pattern="washing machine", path="references/real-world-sizes.md")
```

Search a domain heading the same way.

A domestic washing machine is 600 x 600 x 850 mm. A bullpup rifle is 790 mm
long. Invent a size and everything you place around it inherits the error. Look
it up, then divide by your character height to get CH.

`confidence` — **standard**: a published standard or building code ·
**typical**: settled convention · **approximate**: really does vary.

When the table lacks a size, look it up, read it off a reference image against
something of known size in it, or work it out from a constraint — a door the
player fits through. Then write down where the number came from. An unsourced
number is a guess in a lab coat.

# Editor Markers

- This draws editor-only helpers in the viewport.
- Keep game data separate from these helpers.
- Check it in the open editor.
- `markers.list` — every helper drawn right now.
- `markers.reveal <id>` — show one, so a helper you cannot find says where it is.

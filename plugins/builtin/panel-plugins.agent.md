# Plugin Browser

- Lists plugins and turns them on or off.
- Disabled plugin names live in `project/game.json`.
- A disabled plugin also hides its agent guidance.
- `plugins.list` — every plugin, its category, whether it is on, and what it contributes.
- `plugins.enable <name> [true|false]` — turn one on or off for this project.

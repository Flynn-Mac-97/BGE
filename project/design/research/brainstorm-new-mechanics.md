# Brainstorm: new mechanics

A fresh reviewer brainstormed new mechanics for a grid-backpack roguelite auto-battler, October 2026. It knew the genre only, not
Black Bell, and checked novelty with three shallow web searches. The last column maps each idea onto what Black Bell already has.

| # | Idea | Core rule | Area | Black Bell today |
|---|---|---|---|---|
| 1 | Rune Sockets | An item is a frame with three sockets: trigger, effect, target | Crafting | **The Forge already does this** (WHEN, DO, TO, POWER); it could open to in-run crafting |
| 2 | Item Grafting | Fuse two items: A's trigger with B's effect, at the cost of a scar | Crafting | New; needs the trigger/effect split the rules already have |
| 3 | Item Notes | Write one if-then reaction line on any item, from templates | Crafting | New |
| 4 | Mutation Bay | Items change variant by what they did in a run | Crafting | Mastery tracks floors per item; behaviour-based variants are new |
| 5 | The Museum | Donate an item once a run, with a challenge per slot; sideways rewards, not power | Long-term | New |
| 6 | Heirloom Lineage | A dead hero's chosen item returns, named, scarred and slightly weaker | Long-term | The Heirloom tower rank only raises start levels; item lineage is new |
| 7 | Ladder of Vows | Optional pre-run vows give account rank, not power | Long-term | New |
| 8 | Starter Workbench | Build a starting kit from a points budget earned across runs | Loadout | Kits are fixed per hero today |
| 9 | Pack Habits | Tune the backpack itself over weeks: pockets, cursed corners, holes | Loadout | New |
| 10 | Pre-run Contracts | Carry an unwanted item for N fights for a reward | Loadout | New |
| 11 | Ghost Mentor | Losing to a ghost build unlocks its author's reaction lines for a run | Social | No ghosts today |
| 12 | Replay puzzles | Re-arrange the loser's grid in a saved fight and replay it | Social | Fights are deterministic, so this is cheap |
| 13 | Daily Seed Mutators | The daily run changes one trigger rule | New | New |
| 14 | Cost-and-Cycle Leaderboards | Beat a fixed boss with the fewest items or smallest footprint | New | Deterministic and headless, so cheap |
| 15 | The Hero Is an Item | The hero is a placed tile with its own adjacency | Wild | New; reshapes the game |
| 16 | Betrayal Items | Neglected items build a visible grudge and turn on you | Wild | New |
| 17 | Co-op Backpack | Two players share one grid | Wild | The Duel Pit is same-screen two-player already |

The reviewer's five to build first: Rune Sockets, Starter Workbench, Ghost Mentor, Heirloom Lineage, Cost-and-Cycle Leaderboards.
Kept in reserve: Item Grafting, The Hero Is an Item.

Taken already in the genre (per the reviewer): ghost PvP, proximity bonuses, recipe merging (Backpack Battles, The Bazaar,
Turnbound). The closest prior art for player-built trigger chains is Noita's wand building.
